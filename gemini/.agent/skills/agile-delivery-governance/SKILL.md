# Skill: Gestión y Control de Proyectos

Esta Skill proporciona la estructura metodológica fundamental para documentar, hacer seguimiento y controlar el flujo de trabajo en cualquier tipo de proyecto mediante la correcta definición de sus cuatro pilares operativos: Tareas, Responsables, Tiempo y Entregables.

## 📋 Descripción de los Componentes

### 1. Tareas (`Qué`)

Es el desglose detallado de las actividades necesarias para alcanzar los objetivos del proyecto.

* **Criterio de éxito:** Deben ser específicas, accionables y redactadas con verbos de acción (ej. *Redactar*, *Diseñar*, *Programar*). Evitar generalidades.

### 2. Responsables (`Quién`)

Asignación de la propiedad de la tarea a una persona, rol o equipo específico.

* **Criterio de éxito:** Aunque colaboren varias personas, debe existir **un único líder responsable** de la tarea para asegurar la rendición de cuentas (*accountability*).

### 3. Tiempo (`Cuándo`)

Establecimiento del marco temporal, incluyendo fecha de inicio, duración estimada y fecha de entrega estricta (*deadline*).

* **Criterio de éxito:** Los plazos deben ser realistas e incluir márgenes para imprevistos, ordenados lógicamente según sus dependencias.

### 4. Entregables (`Resultado`)

El producto tangible, digital o verificable que resulta de la finalización con éxito de una tarea.

* **Criterio de éxito:** Debe ser medible y estar directamente alineado con la naturaleza de la tarea (ej. Archivo PDF, repositorio de código, prototipo funcional).

## 🚀 Guía de Aplicación Práctica

Para implementar esta skill en un informe de proyecto, utiliza la siguiente estructura de matriz de control:

| Tarea | Responsable | Tiempo / Plazo | Entregable Esperado |
| :--- | :--- | :--- | :--- |
| **Definición de requerimientos** | Analista de Gestión | 01/Jun - 05/Jun | Documento de Especificación (PRD) |
| **Diseño de Interfaz (UX/UI)** | Diseñador Senior | 06/Jun - 15/Jun | Enlace al Prototipo Interactivo (Figma) |
| **Desarrollo del Frontend** | Desarrollador Web | 16/Jun - 30/Jun | Repositorio en GitHub con rama principal estable |
| **Control de Calidad (QA)** | Ingeniero de Pruebas | 01/Jul - 05/Jul | Reporte de Matriz de Errores corregidos |

---

## 📌 Consejos de Oro para Informes Profesionales

1. **Regla de Correspondencia:** Cada entregable debe validar cuantitativa o cualitativamente su tarea respectiva. Si la tarea es "Capacitar al personal", el entregable debe ser la "Lista de asistencia firmada" o "Certificados emitidos".
2. **Priorización Cronológica:** Organiza las filas de la tabla según el orden temporal de ejecución para facilitar la lectura del informe.
